# EasyGames 

This is our coursework project called **Easy Games**.
We are a team of four and we keep the code simple so any student (and our marker) can run it easily.

## What we are building
- Products (owner stock) CRUD with cost, price, and margin
- Shops (shop stock kept separate from owner stock)
- Customers (basic accounts and status tiers)
- Sales/Checkout (simple POS flow)
- Email groups (later)

## Tech stack
- *Visual Studio Community 2022* (Windows)
- *.NET 8*, ASP.NET Core MVC, EF Core
- *SQL Server Express LocalDB*
- *Git + SourceTree* for branches and PRs
